The input fields come from the [image-to-video schema](https://fal.ai/models/fal-ai/kling-video/v3/standard/image-to-video/api) and motion schema above. Animation uses `start_image_url`, a motion-focused prompt, `duration: "5"`, and `generate_audio: false`. Motion uses `image_url`, `video_url`, `character_orientation: "video"`, and `keep_original_sound: false`. Output composition follows the source; no unverified resolution or latency promise is displayed.

At the least expensive current plan ($1,000 / 48,000 annual credits), a credit represents about $0.02083 in gross revenue. Sixty credits represent $1.25 against $0.42 listed inference cost; ninety represent $1.875 against at most approximately $0.63 for an accepted five-second reference. These are planning calculations, not net profit: payment fees, tax, storage, bandwidth, support, failed paid attempts and account-specific prices are excluded. Do not offer an unlimited generation promise. Inspect actual invoices before expanding allowances; pricing can change.

## Reliability, photo handling and launch boundaries

The [fal queue API](https://fal.ai/docs/documentation/model-apis/inference/queue) supports persistence across HTTP requests. We send one billable POST, store the returned request ID, use safe GETs for recovery, and receive [signed callbacks](https://fal.ai/docs/documentation/model-apis/inference/webhooks). Unknown submissions are held for reconciliation; they are never automatically replayed.

The [file ACL documentation](https://fal.ai/docs/documentation/model-apis/file-access-controls) limits supported private delivery to the v3b CDN. We require that host, exchange the server key for a temporary CDN bearer token, save the MP4 in a private Supabase bucket, then request [payload deletion](https://fal.ai/docs/platform-apis/v1/models/requests/payloads). Deletion requires an admin-scoped key; failures retain a cleanup flag. The requested hosted-file lifetime is 24 hours. Queue payload retention can otherwise last 30 days under fal's [retention policy](https://fal.ai/docs/documentation/model-apis/media-expiration). Original signed links last one hour; user download links last at most 60 seconds.

Public demonstrations are explicitly labeled camera-motion illustrations made from fictional existing portraits. They are not presented as model outputs. Production acceptance still needs consented images/reference clips, measured latency, actual billed cost, likeness review, two-account access checks and deletion confirmation. Commercial use remains subject to the provider's terms and the user's rights in the source files; no unrestricted-rights guarantee is made.
