### Original integration decision (superseded by fal transport)

Pinned model: `gpt-image-2.5-sunburst-2026-09-08`. `POST https://api.openai.com/v1/images/edits`, multipart `image[]`, `prompt`, `model`, `quality`, `size=1024x1536`, `output_format=png`, `n=1`. It does not send unsupported legacy `input_fidelity` settings. No provider fallback silently changes the model. This recommendation is a documentation-based fit assessment, not a demonstrated claim of superior likeness.

End users see **one generation from three daily allowances**, not an invented dollar price. The operator funds API use. Successful responses store the actual usage object for cost analysis. The initial global cap is 50 attempts/day; this is an attempt cap, not a dollar guarantee. Configure provider project spend controls separately.

## Search intent and on-page implementation

| Intent     | Relevant wording found in trend reporting / search results       | Product response                                                                                                   |
| ---------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Create now | AI retro portrait generator; 80s AI photo; 1980s photo generator | Working studio near the top, three presets, upload, visible allowance, generation and downloads.                   |
| Learn how  | 1980s AI photo prompt; how to make a retro portrait              | Original instructions, selfie tips, explanation of AI editing versus color filters; no prompt-writing requirement. |
| Evaluate   | will it look like me; retro photo privacy; generation cost       | Explicit likeness caveat, private handling details, cost/allowance explanation and original/result comparison.     |
| Share      | before and after retro photo                                     | Labeled local composition download; no automatic social posting.                                                   |

No paid keyword tool or Search Console account was available. These are qualitative intent groupings, not volume/ranking predictions. The homepage is prerendered HTML, with a descriptive title, canonical, metadata, generated Open Graph card, WebApplication JSON-LD, robots and sitemap. No fictional reviews, aggregate ratings, usage statistics, FAQ rich-result promise or HowTo markup. Three optimized local WebP demonstrations include honest alt text and fixed layout dimensions. System typography avoids remote font requests.

After launch: configure the real canonical domain, submit the sitemap in Search Console, inspect indexation, measure impressions/clicks by relevant query and country, and collect real Core Web Vitals. Prioritize useful improvements based on evidence; do not create thin keyword/location pages.
